# 运行与开发

从项目根目录执行命令。Python 环境为 `runtime/app-env`，通过 `scripts/deployment/project_python.py` 加载本项目配置。

| 内容 | 入口 |
|---|---|
| 后端 API | `src/pbpk_kb/api/main.py` |
| Streamlit | `src/pbpk_kb/ui/streamlit_app.py`、`ui/pages/` |
| 数据来源与设置 | `src/pbpk_kb/config/` |
| 数据库结构 | `src/pbpk_kb/storage/schema.sql` |
| 收集和处理流水线 | `src/pbpk_kb/acquisition/`、`processing/`、`pipeline_utils.py` |
| 组件推荐 | `src/pbpk_kb/recommendation/online_agent.py` |
| 模型排序与训练 | `src/pbpk_kb/recommendation/model_matching/` |
| 蓝图与模拟 | `src/pbpk_kb/blueprints/`、`model_runtime/`、`model_assets/` |

```bash
runtime/app-env/bin/python scripts/deployment/project_python.py -m pbpk_kb.main --help
mkdir -p runtime/deployment/test_tmp
runtime/app-env/bin/python scripts/deployment/project_python.py -m pytest tests -q -o addopts= -p no:cacheprovider --basetemp=runtime/deployment/test_tmp
```

部分 GPU、数据库和外部网络测试有专门的启用条件。测试临时输出可删除；生产数据库、模型权重、已注册资产和证据原文不可作为缓存删除。

服务操作见 [部署](部署.md)，科学处理合同见 [证据流程](证据流程.md) 和 [推荐策略](推荐策略.md)，下一轮任务见 [研究计划](研究计划.md)。导出文件由 API 按需生成。

### 核心实现与复用边界

| 实现 | 作用 |
|---|---|
| `blueprint_policy/exposure_profile.py` | 开发采样窗面积约束非肾CL，外层优化分布和交换 |
| `blueprint_policy/condition_matched_selection.py` | 保留的证据成组适用性检查 |
| `blueprints/evidence_blueprint.py` | 校验证据账本，构建人体、药物、给药快照 |
| `blueprint_policy/transport_calibration.py` | 论文血管—组织双区方程与固定校准范围；旧文件不原地修改 |
| `blueprint_policy/perfusion_export.py` | 从原生模型导出人体生理与药物分配，保留参数读回 |
| `blueprints/extended_prediction.py`、`clinical_prediction_nca.py` | 同一轨迹的终点与临床采样NCA |
| `blueprints/source_adaptation.py` | 完整可复用模型的来源适配工具，属于模型复用路径 |

上述文件均位于`src/pbpk_kb/`。原版接口和论文绑定代码保留，退役实验的结果入口不再列为当前运行指令。工程可执行不等于临床准确；同研究臂群体摘要不等于个体参数相关性。缺少定量参数或无适用机制时返回缺口，不把完整同药模型或目标观测偷偷作为构建输入。

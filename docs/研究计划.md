# PBPK 模型推荐研究计划

更新：2026-09-22（明确模型推荐与蓝图构建的边界；推荐实验沿用 09-14 主线）。目标是评估推荐算法能否为具体用途选出合适的 PBPK 模型，并在独立观测上验证推荐后果。现有 30 种药物、2,872 条证据、202 个模型族和 280 个版本保留。

模型能够满足请求时，由模型推荐负责推荐和复用。蓝图设计面向**没有模型或现有模型不支持用途**：人体基础 PBPK + 药物证据 + 给药条件和目标终点 → 新药物模块或必要机制补充 → 可执行模型；缺核心证据则交付缺口草案。已新增从整理后的参数证据生成成人单药单次模型的实现；任意药物、自动补证据和新机制补齐仍未完成，已有完整来源适配和校准仅作为可复用工具。具体算法见[方法定义](推荐策略.md#blueprint-method)，评价安排见[第 9 节](#blueprint-experiments)。第 1–8 节仍为公共模型推荐任务；蓝图实验不沿用推荐兼容标签，旧大规模搜索队列保持停止。

## 1. 先纠正评价目标

旧目录兼容标签由同药物和覆盖规则生成，输入特征又包含同一信息。这轮训练已停止，启动入口已禁用；结果仅用于解释问题，不进入论文主对照，也不再补跑种子。[审计](../experiments/model_recommendation/runs/expanded_catalog_20260913/lambdamart_audit.json)

多加几个排序指标不能消除这个问题。新评价必须区分：找到相关模型、判断用途、同药物模型择优、推荐模型的真实预测表现。下面是本项目拟采用的协议，不是文献已经替我们验证过的结论。

**接入优先级（研究判断，尚无 PBPK 成绩）**：先做 Qwen3 专用检索/重排、ReasonRank、Rank-R1，以及 G-reasoner 图检索；F2LLM-v2 和 Jina v3.5 作为最新技术报告对照；Gelato 在图语义与规模适配通过后加入结构对照；REARANK 与 GFM-RAG 可作对应方法的前代对照。所有候选仍使用独立评价数据，冻结代码、权重、提示词、候选顺序/窗口与推理预算。全量外部方法推理已于 2026-09-14 启动，结果和命令见 [模型实验入口](../experiments/model_recommendation/README.md)。旧训练不恢复，自研算法开发暂停。

## 3. 标签必须有独立依据

以“药物 + 人群 + 给药途径/剂型 + 剂量/方案 + 用途/端点”为一个需求场景。候选保留模型族、版本、源码校验值及用途，不把同一模型的多个文件算成多个独立模型。

两类答案分开：

- **文献适用性**：依据独立留出的报告/研究，由盲评判定可直接复用、需明确适配、仅能作机制参考、不适用。记录引用、评判人和分歧；有条件时双人独立标注并仲裁。LLM 可辅助整理，不作为独立裁判。
- **执行预测能力**：在未参与该 PBPK 模型建模、参数拟合或选择的研究上，比较真实观测与执行输出。事后把拟合数据称为验证数据不成立。旧模型开发角色不明的研究，先记“独立性待核”。

等级 0/1/2/3 对应不适用/机制参考/受控适配/直接复用；没有足够资料记 null。等级不能直接由身份、覆盖数、已有推荐分数或旧验证等级复制。文献适用性通过不等于已验证预测准确。

判定“没有适用模型”需要在预先规定的候选池内完成审查；未下载、未运行或无观测都是未知，不是负例。方法提交的预测文件不能自带并覆盖答案。

输入和答案隔离到研究/来源层级：同篇文章的不同片段仍是同一来源。隐藏评价研究的曲线、端点、结论及衍生的 validation_grade、适用标签等，不能只删除答案那一列。预训练模型的潜在公开数据记忆无法仅靠 ID 审计排除，需做时间留出及来源污染分析。

## 4. 同类与跨类分别评价

| 场景 | 真正回答的问题 | 不能混淆的事项 |
|---|---|---|
| 全库内容检索 | 是否找到有依据的相关候选 | 全部 280 个版本参与打分；未判定项不自动设为不相关 |
| 同药物、同用途、不同模型族 | 哪个模型更适合该研究 | 主择优任务；至少两个独立模型族且有可区分的判断/误差 |
| 同药物、同族不同版本 | 版本变化是否改善适用性 | 单列版本比较，不能扩充独立模型族数 |
| 同药物、新剂量/人群/途径 | 能否推广到新场景 | 研究级留出；给药途径不能直接换名视为已适配 |
| 同机制、不同药物 | 是否能找到机制参考或可验证的迁移起点 | 与直接复用分开，不能因为机制类似就当可预测新药 |
| 不同机制/无合适候选 | 是否拒绝不支持的建议 | 分清不适用与未知，不追求推荐数量 |

每个方法必须提交相同请求和预先固定候选池的全部分数，禁止各自抽少量容易的负例。文献审查池先覆盖全部同药物候选，并包含各方法候选并集及预先抽取的困难负例；披露未审查覆盖率。只有完全判定的请求池才进入完整列表的主要排序指标，池内结果不能冒称全库召回。

## 5. 多维指标与分母

主要排序指标预先定为同药物独立家族的 NDCG@5；关键共同结局为独立 PK 研究的选择遗憾和误推荐率。指标无定义或没有数据时输出 null 与原因，不能用 0 或 1 填充。

| 维度 | 指标 | 解释和边界 |
|---|---|---|
| 检索与排序 | NDCG@1/3/5/10、Recall@k、MRR；同药物成对择优准确率 | 同一类型的互补指标；无正例请求另外评价拒绝，不计满分；同分择优记 0.5 |
| 用途判断 | 四类用途 Macro-F1/混淆矩阵；二元适用性 F1 | 按类给支持数；文献适用性和执行通过分别计算，不能强行从排序分数推类别 |
| 错误建议与拒绝 | 不适用候选被推荐比例、无适用模型时拒绝率、有适用模型时错误拒绝率 | 全零拒绝不能因误推荐率低而被判最好，同时报告覆盖率 |
| 实际预测 | AUC、Cmax 分别报告 GMFE、AFE/偏差；浓度曲线的对数误差；预设容差内比例 | 同研究同端点同单位；不把全部采样点当独立样本，不统一硬套“两倍即成功” |
| 推荐后果 | Top-1 执行成功率、验证通过率、选择遗憾 | 遗憾 = 选中模型误差 − 同场景已完整验证候选中的最小误差；执行失败和未知单列，不能只报成功运行子集 |
| 概率可信度 | Brier、ECE、风险—覆盖曲线/AURC | 概率及拒绝阈值只在验证集校准；原始相似分不是概率 |
| 稳健性 | 等义改写一致性、删证据后的变化、剂量/人群改变后的合理响应 | 等义变换应稳定，科学约束改变时不要求盲目不变 |
| 可用性 | 证据支持率、错误引用率、有效模型族覆盖；P50/P95 时延、显存、吞吐 | 多样性仅在合格候选中讨论，不用不适用药物增加“多样性” |

有个体观测与虚拟人群分布时再加 CRPS/预测区间覆盖，不能从单条均值曲线虚构分布。[CRPS 论文](https://doi.org/10.1002/psp4.70175)

不把上述维度任意加权成一个总分。主结论同时展示排序、实际预测、错误建议与覆盖的取舍。

## 6. 切分与公平比较

分别设立已知药物新研究、未见药物、未见模型族三个任务，不能把三种泛化混成一张表。按真实研究/论文及复用数据组切分；重复版本和共同开发数据不得跨越对应的冷启动边界。DDI 大连通组造成有效留出药物不足时如实披露，用可解释的任务分别评估，不能拆开泄漏，也不能把两个药物称为全面泛化。

先锁定每个任务的候选池、主要指标、来源隔离、适用容差和调参预算，再训练。每方法同样的可用输入、调参机会和硬件条件；所有参数、阈值、检查点只由训练/验证集决定。零样本与微调结果分表；重排器全候选打分与两阶段召回分别报告，后者同时报告召回上限。

现有评估集已被反复查看，后续不能作为新模型唯一的最终检验。开发期采用按研究/药物分组的外层评估与内层调参；最终补时间较晚且从未用于选择的新研究。若无法获得，明确报告分组交叉验证及其限制。

随机方法使用 5 个预先固定种子，报告所有种子及均值；确定性方法不制造五个“重复样本”。按药物/研究聚类 bootstrap 给配对差值的 95% 区间，多模型比较做 Holm 校正。有效样本数是独立药物/研究数，不是请求×候选数或曲线点数。药物数不足时不作显著性和广泛泛化结论。

## 7. 新模型开发的可检验假设（暂停开发）

最小路线：结构化需求与单位归一 → 文本候选匹配 → 类型化组件证据图交互 → 同药物候选排序 → 独立适用性与拒绝输出。新模型只使用推荐时确实可取得的信息。

先检验三个假设：文本交互是否改善同药物差别识别；组件证据是否在文本强基线之上增加有效信息；显式约束与校准是否降低错误用途建议。通过独立标签、分组验证训练排序和适用性任务，不能继续优化旧标签满分。

对应消融仅保留去组件证据、去图结构、去约束、去校准；所有版本共用数据与调参预算。分子信息对同药物择优几乎不提供候选差异，只有跨药物参考/迁移任务有科学理由时才单独加入。模型名称与“创新点”在实验验证前不定为结论。

## 8. 当前落地与仍缺的证据

[可用数据盘点](../experiments/model_recommendation/scientific_evaluation/readiness.json)记录已有真实执行及缺口。已有 Rosuvastatin 验证资料、受控适配成功/失败及其他 Windows 模型输出可复用；Moxifloxacin 14 条曲线仅有工程验收，不能当独立科学 gold。旧执行负例中存在无观测协议，必须改按未知处理。这里的角色核验不能靠 LLM 宣称完成。

已实现 [独立评估入口](../src/pbpk_kb/recommendation/model_matching/scientific_evaluation.py)：全量候选一致性、拒绝规则标签、来源交叉检查、排序/同药物比较、适用性和概率校准、分组支持数。输入审计通过仅说明记录内部一致，不保证人工来源声明真实，不自动签发科学认可。

当前适用性实现为二元分类；已补候选级和请求级推荐/拒绝覆盖、误拒绝、风险—覆盖曲线及 AURC。置信度并列作顺序无关处理，缺失决策保持未知。四类用途预测、独立 PK 选择遗憾和聚类统计仍待补齐。外部对照已接入全量句子重排与机制支持删减，约束变化和新研究泛化仍需独立答案。同药物家族指标要求每家族预先指定一个代表，重复版本池只报告版本层结果；支持 DDI 多药物成员。逐请求结果保留药物和研究标识，供后续配对统计。

评估入口读取单个 JSON：queries 保存请求/药物/研究/任务/候选池/输入证据/开发研究；judgments 保存独立等级、适用性、引用研究、模型族及药物成员，未知项明确为 null；predictions 保存方法/种子/候选分数及可选适用性概率。所有方法逐请求提交完整候选池。CLI 为 `python -m pbpk_kb.recommendation.model_matching.scientific_evaluation --input 独立基准.json --output 评估结果.json`，使用项目 Python wrapper；这里的输入名是占位，当前尚未生成经独立核验的基准。

2026-09-14 的阶段快照为：已提取并重算 389 条历史 PK 记录，去重后为 270 条观测系列，与 22 个当时候选工件精确匹配；其中 13 个候选有观测。更新库存见[资料就绪清单](../experiments/model_recommendation/scientific_evaluation/readiness.json)，不能把两次不同范围的快照相加。首个观测时间均大于零，因此只能称“观测窗口 AUC”，Cmax 也仅指采样网格峰值。当前请求尚不能精确连接这些研究场景，不能计算独立选择遗憾。尚未完成：独立判断的归一化与盲评、全部模型开发来源核验、共同 PK 端点的独立家族比较及部分外部图/生成式方法接入。自研新模型训练暂停。旧规则标签不能转换成这套入口的 gold 来跳过这些工作。

执行顺序保持简洁：先整理已有独立资料与同药物候选 → 冻结可评估任务 → 同一入口跑全部适用基线 → 针对失败模式开发最小改进并做消融 → 对未接触的新研究做最终验证。无需重新下载整个知识库，也不要求先把 280 个版本全部模拟完才能开始文献适用性任务。

Streamlit 保持关闭；不调用 LLM 生成评测真值，不启动旧弱标签训练。模型下载/后续 GPU 推理仅使用本项目资源。




## 9. 蓝图设计：自动构建与补充观测更新

使用人体PBPK基础模板和来源可追溯的药物信息，在没有适用现成模型时构建模型。当前有开发曲线分支保留四参数血管—组织交换与血细胞分配校准；无本药曲线路径另外评价，不混用两类成绩。完整实现规则统一放在[推荐策略第8节](推荐策略.md#blueprint-design)，本文件只保留研究问题和验收方向。

**当前方法主线：人体模板与药物证据 → 未知参数校准 → 可行性检查与必要修复 → 目标条件预测。** 有本药开发观测时，未知CL由开发曲线校准估计；合格药物证据、fu等必要输入及其来源保留。正文描述和图表统一展示当前方法，不再标注RF或展开RF使用说明。RF实际输入来源、消融及RF、TabPFNv2和CL增强集成的参数测试、直接预测与校准后比较集中在论文附录表E.6附近。已有实验数值直接保留，不因展示调整重新运行。参数处理与复现边界见[推荐策略](推荐策略.md#blueprint-rf-role)及8.13。

当前主要问题：**用简单时间覆盖补充开发观测，检验自动构建与更新PBPK的实际价值。** 直接使用既有时间规则，不再以学习选点器胜过时间规则作为研发目标或论文成立前提。需要分别检验：

1. 相比不补点，补充信息是否改善独立目标研究的预测。
2. 相同开发观测、相同目标下，完整PBPK流程与一室、两室等经典模型表现如何；不预设必须全面胜出。
3. 证据约束、可行性检查及来源记录是否有可核验的构建与诊断收益。声称节省观测时必须另有匹配误差的预算实验，不从一次补点改善直接推断。

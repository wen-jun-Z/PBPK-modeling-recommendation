组件生成一次只执行一个 GPU 任务。2026-09-06 已修复忙碌时返回 422 的问题：相同请求共享正在生成的结果，不同请求等待 GPU 空闲；已保存结果仍优先读取。进程内还保留最多 16 个、60 秒内完成的结果，覆盖生成完成到数据库入库之间的重复请求窗口；入库使用本项目数据库的事务锁，继续严格检查已有结果的 checksum，避免重复提交撞上插入竞态。页面显示等待文字和已用时间。`GET /recommendation/runtime-status` 返回运行、等待和共享等待者数量，完成或异常后释放相应状态。科学校验失败仍按原门禁报告。

真实并发验收：同时提交 A、A、B 三条请求，三条均返回 HTTP 200；两个 A 得到相同结果 ID，B 得到独立结果。观测到最多 1 个任务运行、1 个不同任务等待、1 个相同请求共享等待，完成后全部归零。记录见 `runtime/deployment/component_concurrency_test.json`。启动脚本等待数据库、API、GPU 嵌入服务和网页全部就绪后才报告成功。
